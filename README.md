# Prerequisites 📌 
Before running the project, ensure you have a basic understanding of:
- Node.js
- React.js
- Express.js
- MongoDB
- TypeScript

⚙️ Installation
# Install dependencies
npm install

# Build the backend
npm run build

# Env Variables 🔑

Make Sure to Create a  .env file in root directory and add appropriate variables in order to use the app.

**Essential Variables**
PORT= `4000 or any`
MONGO_URI= `Mongodb Atlas uri or mongodb://localhost:27017`
STRIPE_KEY=`stripe secret key`
PRODUCT_PER_PAGE=`8 or any`
CLOUD_NAME=`your cloudinary cloud name`
CLOUD_API_KEY=`your cloudinary api key `
CLOUD_API_SECRET= `your cloudinary api secret`
REDIS_URI=`redis cloud uri or redis://localhost:6379`
REDIS_TTL= `14400 or any`
CLIENT_URL=`http://localhost:5173 (common for VITE projects) or http://localhost:3000 (common for Create React App) or your versel url`

_fill each filed with your info respectively_

# Features 🚀
- User authentication & authorization
- Product listing with pagination
- Secure payment integration using Stripe
- Image upload & management via Cloudinary
- Caching with Redis for optimized performance
- Responsive frontend built with React

# Tech Stack 🛠️
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Cache: Redis Cloud
- Image Hosting: Cloudinary
- Payments: Stripe
